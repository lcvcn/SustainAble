# 🌱 SustainAble

Benvenuti nel repository di **SustainAble**, un progetto di Editoria Digitale pensato per ispirare e informare giovani dai 18 ai 25 anni sul tema della sostenibilità. Il nostro obiettivo è creare contenuti affidabili, aggiornati e facili da consultare, sfruttando un flusso di produzione documentale **automatizzato** e **multicanale**. 

## Descrizione del progetto

Questo progetto nasce per dare voce a soluzioni pratiche e dati scientifici sul cambiamento climatico, integrando diverse tecnologie per produrre contenuti aggiornati in vari formati. Il workflow prevede:

1. **Raccolta dati e analisi dei trend**
2. **Validazione**
3. **Produzione automatizzata**
4. **Distribuzione multicanale**
